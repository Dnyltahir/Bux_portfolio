# Bux Portfolio

Portfolio website for Muhammad Bux, Communication Designer and Visual Artist based in Lahore, Pakistan.

Built with Next.js, React, TypeScript, Tailwind CSS and Framer Motion.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Other commands

```bash
npm run build      # production build
npm run typecheck  # TypeScript check
```

## Where things are

- `app/` — pages (`page.tsx` is the homepage, `work/gourmet-cola/` is the case study) and global styles
- `components/` — sections of the site and shared pieces
- `lib/projects.ts` — the project list, contact details and social links
- `public/assets/` — logo files, portrait, client logos and the CV
- `legacy-static/` — the earlier plain HTML version, kept as a backup

Project cover images are loaded from Behance for now.
